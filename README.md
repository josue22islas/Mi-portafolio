# Portafolio de Josue Islas

Portafolio profesional de desarrollo web y movil, construido con HTML, CSS y JavaScript.

## Contenido

- Presentacion profesional y enlaces de contacto.
- Interfaz en espanol e ingles.
- Temas claro y oscuro.
- Recursos visuales, animaciones y curriculum descargable.

## Ver en local

Abre `index.html` en un navegador. Para trabajar con un servidor local, puedes usar la extension Live Server de Visual Studio Code.

## Estructura

- `index.html`: pagina principal.
- `assets/`: estilos, scripts, imagenes, videos y documentos.
- `technova-logo.html`: vista del logotipo.
- `experimentos/`: pruebas visuales independientes.
- `pruebas/`: scripts y notas de validacion.
